# LibroLink

A Library Management System made with Java (OOP). Admin and Member logins, borrow (rent per day) or buy books, payments, and reports.

## Try it online
- Real Java app in the browser: `run.html`
- Web demo: `index.html`

(Add your GitHub Pages link here: https://YOUR-USERNAME.github.io/LibroLink/run.html)

## Run it in NetBeans
1. Create a new Java Application project (uncheck "Create Main Class").
2. Copy the `library` folder from `src` into your project's `src` folder.
3. Right-click `Main.java` and choose Run File.
